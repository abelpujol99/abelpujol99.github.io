Ability Maker - Pounce Palace

Pounce Palace is a first-person platformer game where the player has to acquire movement skills and learn how to use them in order to defeat the enemies in their path to complete the level.
This game was developed in Unity.

Due to time constraints, Pounce Palace could only have 2 types of enemies implemented. But, throughout the game, the players can see variations of the same enemies. This was achieved by developing a tool, allowing the enemy designers to iterate without having to communicate with the AI developer, which in that case was me.

Implementation

In order to allow fast iterations, some data assets for enemy type and ability type were defined. To maximize enemy designers' performance while iterating, each data asset has their own Custom Editor. These editors were implemented to add:

  • Text Hightlights
  • Indents
  • Folders
  • Conditions

The conditions had great importance, hiding or showing fields in cascade depending on the entries' values. Due to this, these data assets were structured to be fulfilled from the top to the bottom.

With this tool, and the systems that back it, we created variations of the same enemy type.
